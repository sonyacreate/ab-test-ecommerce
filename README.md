# A/B-тест: анализ нового дизайна ecommerce

## О проекте

Аналитический кейс по результатам A/B-теста интернет-магазина.

**Бизнес-вопрос:** даёт ли новый дизайн посадочной страницы измеримое улучшение конверсии и есть ли основания менять текущий вариант?

В проекте пройден полный аналитический цикл:

**качество данных → корректность эксперимента → метрики → статистическая значимость → неопределённость эффекта → практическая значимость → бизнес-решение.**

---

## Бизнес-контекст

Компания разделила пользователей на две группы:

- **Control** — старый дизайн;
- **Treatment** — новый дизайн.

### Primary metric

**Conversion Rate (CR)** — доля пользователей, совершивших целевое действие.

### Гипотезы

- **H0:** конверсия в Control и Treatment одинакова;
- **H1:** конверсия в группах различается.

Уровень значимости: **α = 0.05**.

Бизнес-контекст при этом остаётся направленным: для rollout нас прежде всего интересует улучшение конверсии. Но статистический тест в проекте проверяет наличие различия в обе стороны, после чего направление и величина эффекта интерпретируются отдельно.

---

## Данные

Источник: [Kaggle — E-Commerce A/B Testing dataset](https://www.kaggle.com/datasets/putdejudomthai/ecommerce-ab-testing-2022-dataset1)

Исходный датасет:

- **294 480** строк;
- `user_id`;
- `timestamp`;
- `group`;
- `landing_page`;
- `converted`.

После проверки качества и очистки: **290 585 пользователей**.

---

## Что было сделано

### 1. Data quality

Проверены:

- пропуски;
- распределение пользователей по группам;
- соответствие `group` и `landing_page`;
- дубликаты `user_id`.

Обнаружено:

- **3 893 строки (1.32%)** с несоответствием группы и страницы;
- **2 повторные записи по `user_id`**.

Некорректные наблюдения исключены из основного анализа: причина несоответствий неизвестна, поэтому исправлять их вручную было бы домыслом.

### 2. Conversion Rate

Рассчитана CR отдельно для Control и Treatment и оценена абсолютная и относительная разница.

### 3. Statistical test

Использован **двусторонний z-test для двух пропорций**.

Результат рассматривается вместе с размером эффекта и доверительным интервалом, а не изолированно по p-value.

### 4. Confidence interval

Для разницы:

**Treatment − Control**

рассчитан **95% CI методом Newcombe**.

### 5. MDE и power

Рассчитан **MDE (Minimum Detectable Effect)** при:

- α = 0.05;
- power = 80%;
- baseline = CR Control.

### 6. Experiment diagnostics

Дополнительно проверены:

- SRM (Sample Ratio Mismatch);
- длительность эксперимента;
- дневная динамика CR;
- стабильность эффекта в первой и второй половине эксперимента.

Эти проверки используются как диагностика качества эксперимента и не заменяют основной статистический тест.

### 7. Effect size

Рассчитан **Cohen's h**, чтобы оценить величину различия независимо от одного только p-value.

---

## Результаты

| Метрика | Control | Treatment |
|---|---:|---:|
| Пользователи | 145 274 | 145 311 |
| Conversion Rate | **12.04%** | **11.88%** |

**Наблюдаемый эффект Treatment − Control: −0.16 п.п.**

Относительное изменение относительно Control: **−1.31%**.

- **p-value ≈ 0.19** — статистически значимого различия при α = 0.05 не обнаружено;
- **95% CI** для разницы включает 0;
- **Cohen's h ≈ 0.0049** — наблюдаемая разница очень мала;
- **MDE ≈ 0.34 п.п.** — ориентир минимального эффекта, который тест способен обнаружить при заданных параметрах мощности.

### Важный вывод

Отсутствие статистической значимости **не означает, что новый дизайн доказанно хуже**.

Корректный вывод:

> **текущий эксперимент не подтвердил улучшение конверсии.**

---

## Бизнес-решение

На основании основной метрики новый дизайн **не показал подтверждённого улучшения CR**.

Поэтому я бы **не рекомендовала полный rollout как доказанное улучшение**.

Следующие шаги:

1. проверить исходную продуктовую гипотезу;
2. определить минимально значимый для бизнеса эффект;
3. при необходимости спланировать новый эксперимент с достаточной мощностью;
4. заранее определить guardrail-метрики — например, ошибки, возвраты, revenue per user или другие доступные бизнес-метрики.
