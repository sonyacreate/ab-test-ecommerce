# A/B-тест: стоит ли раскатывать новый дизайн страницы?

## Описание проекта
Анализ результатов A/B-теста интернет-магазина на реальных данных Kaggle.
Цель — определить, приводит ли новый дизайн страницы к статистически 
значимому росту конверсии, и дать рекомендацию продакт-менеджеру.

## Бизнес-контекст
Компания протестировала новый дизайн посадочной страницы на части 
пользователей. Перед командой стоит вопрос: раскатывать новый дизайн 
на всех пользователей или оставить старый? Неверное решение может 
стоить бизнесу конверсии и выручки.

## Данные
- Источник: [Kaggle — E-Commerce A/B Testing dataset](https://www.kaggle.com/datasets/putdejudomthai/ecommerce-ab-testing-2022-dataset1)
- Исходный размер: 294 480 строк
- Колонки: `user_id`, `timestamp`, `group`, `landing_page`, `converted`
- После очистки: 290 585 строк

## Методология

### 1. Чистка данных
В реальных данных редко всё идеально — и здесь тоже нашлись проблемы:
- **3 893 строки** с нарушением рандомизации: пользователь из группы 
`treatment` видел `old_page` или из `control` видел `new_page`. 
Причина неизвестна — удалены, чтобы не искажать результаты
- **2 дубликата** по `user_id` — один пользователь попал в обе группы, 
что нарушает чистоту эксперимента. Удалены

### 2. Анализ конверсии
Посчитали среднюю конверсию в каждой группе и визуализировали разницу.

### 3. Z-test
Проверили статистическую значимость разницы между группами.
Порог значимости: p-value < 0.05.

### 4. Effect Size — Cohen's h
Оценили практическую значимость разницы — насколько она важна 
для бизнеса даже если была бы статистически значимой.

## Результаты

| Метрика | Контроль | Тест |
|---------|----------|------|
| Пользователей | 145 274 | 145 311 |
| Конверсия | 12.04% | 11.88% |
| Разница | -0.16% | |

- **Z-статистика: 1.31** — небольшое отклонение между группами
- **P-value: 0.19 > 0.05** — разница статистически случайна, 
  нельзя утверждать что новый дизайн влияет на конверсию
- **Cohen's h = 0.0049** — эффект практически нулевой, 
  даже меньше порога "маленького эффекта" (0.2)

## Гипотезы
- **H0 принята:** конверсия в группах статистически не отличается
- **H1 отвергнута:** новый дизайн не доказал превосходства над старым

## Вывод и рекомендации

Новый дизайн не показал статистически значимого улучшения конверсии.  
Конверсия в контрольной группе составила 12.04%, а в тестовой — 11.88%. Разница между группами равна -0.16%, при этом p-value = 0.19, что выше порога значимости 0.05.

Это означает, что на текущих данных нельзя утверждать, что новый дизайн положительно влияет на конверсию. Кроме того, значение Cohen's h = 0.0049 показывает, что практический эффект почти отсутствует.

### Рекомендация для продукта

Не стоит раскатывать новый дизайн на всех пользователей. Вместо этого лучше:

1. Проанализировать, какие именно элементы нового дизайна могли снизить конверсию.
2. Сформулировать более точную продуктовую гипотезу.
3. Запустить новый A/B-тест с заранее рассчитанным MDE и достаточной мощностью.
4. Отслеживать не только основную метрику конверсии, но и guardrail-метрики: отказы, время на странице, количество ошибок, выручку на пользователя.
